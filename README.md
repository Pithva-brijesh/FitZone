## 📖 Overview

FitZone is a full-stack fitness management web application that enables users to build healthy habits by combining workout management, nutrition tracking, progress visualization, and achievement-based motivation into one platform.

The application provides a modern dashboard where users can create workout routines, complete guided workout sessions, log meals, monitor nutrition, visualize progress, unlock achievements, and maintain workout streaks.

This project was developed as a major academic project while following real-world software development practices including authentication, database management, deployment, and responsive UI design.

# ⚙ Installation

Clone the repository

```bash
git clone https://github.com/Pithva-brijesh/Fitzone.git
```

Go into the project

```bash
cd Fitzone
```

Install dependencies

```bash
npm install
```

Start the development server

```bash
npm run dev
```

---

# 🔑 Environment Variables

Create a `.env` file.

```
VITE_SUPABASE_URL=your_supabase_url

VITE_SUPABASE_ANON_KEY=your_supabase_anon_key
```
